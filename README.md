# ULTROX AI – Intelligent Rule-Based Chatbot

ULTROX AI is a modern, browser-based rule-driven chatbot designed to provide quick responses, basic calculations, programming tips, cybersecurity information, and system-related utilities.

The project uses **HTML, CSS, and JavaScript** and runs completely in the web browser without requiring a backend server.

https://charansaibheemireddy.github.io/CODESOFT-chatbox/

## 🚀 Features

- 🤖 Rule-based AI chatbot
- 💬 Interactive chat interface
- 🌙 Modern dark/neon UI
- 🧮 Basic mathematical calculations
- 💻 Programming tips
- 🔐 Cybersecurity tips
- 😂 Random jokes
- 🕒 System time and date
- 🖥️ Browser/system information
- 📋 Command list
- 🧹 Clear conversation
- 🆕 New conversation
- 💾 Chat history using LocalStorage
- ⌨️ Keyboard shortcut support
- 📱 Responsive design for mobile and desktop
- 🛡️ Safer message rendering using `textContent`
- ⚡ No backend required
